WL Simplistic SnowRunner Mod Editor v1.2.0L
QUICK FEATURE GUIDE
Creator: Wicked Lord

Values are multipliers unless noted: 1.00 = stock, 1.50 = +50%, 0.50 = half.

TARGETS / TOOLS
Truck target - Choose All Trucks, a whole truck class, or one truck.
Scan Trucks - Refresh official trucks from initial.pak.
Scan Mods - Finds supported installed third-party mod trucks.
Preview Changes - Shows what would change without writing the PAK.
APPLY MODS - Writes the selected changes.
Restore Original - Restores WL's protected original backup.
Check for Updates - Checks for a newer WL editor release.

ENGINE / FUEL / STEERING
Engine torque - Multiplies engine pulling power.
Engine responsiveness - Changes how quickly the engine responds.
Engine fuel consumption - Multiplies engine fuel use.
Truck fuel capacity - Multiplies the truck's fuel tank capacity.
Maximum steering angle - Multiplies maximum wheel steering angle.
Steering response - Multiplies steering and return response speed.

DRIVETRAIN / GEARBOX
Always AWD - Makes AWD permanently available/on where supported.
Always differential lock - Makes differential lock always available where supported.
Extreme durability (GLOBAL) - Global high-durability mode; affects the whole game data set.
Gearbox fuel consumption - Multiplies gearbox-related fuel use.
AWD fuel penalty - Multiplies the extra fuel use caused by AWD.
Idle fuel use - Multiplies fuel used while idling.
Gear tuning - Adjusts gearbox progression/top-speed behavior where supported.
Gearbox durability - Multiplies gearbox damage capacity.

TIRES
Tire asphalt grip - Multiplies asphalt traction.
Tire off-road grip - Multiplies dirt/off-road traction.
Tire mud grip - Multiplies mud/substance traction.
Tire durability - Multiplies tire damage capacity.
All tires ignore ice - Gives supported tires SnowRunner's native ignore-ice property.
Official compatible alternate tire families, including tested JAT/Ultima tires, are supported.

SUSPENSION
Suspension strength - Multiplies suspension spring strength.
Suspension height - Multiplies supported suspension height/travel values.
Suspension damping - Multiplies damping; higher values reduce bouncing more strongly.
Suspension durability - Multiplies suspension damage capacity.

WINCH / CRANE
Winch strength - Multiplies winch pulling strength.
Winch length - Multiplies winch cable length.
Autonomous winches - Allows supported winches to work without engine ignition.
Crane strength - Multiplies supported crane motor/constraint force.
Crane speed - Multiplies supported crane movement speed.

DURABILITY / SERVICE / CARGO
Engine durability - Multiplies engine damage capacity.
Fuel tank durability - Multiplies fuel-tank damage capacity.
Service fuel capacity - Multiplies fuel carried by supported service addons.
Service water capacity - Multiplies water carried by supported service addons.
Service repair points - Multiplies repair points on supported service addons.
Service spare wheels - Multiplies spare-wheel capacity on supported service addons.
Cargo mass - Multiplies supported cargo physical mass.

UNLOCKS / ECONOMY
Unlock all trucks - Removes supported truck unlock requirements.
All trucks in all regions - Makes supported trucks available across regions.
Truck prices - Multiplies truck purchase prices.
Upgrade/addon prices - Multiplies supported upgrade/addon prices.
Unlock all upgrades/addons - Removes rank/exploration requirements for supported upgrades/addons. Category targets now include map-discovery upgrades tied to that category. The checkbox remains available and preserves its state when switching from All Trucks to an individual truck because this unlock is global.

STABILITY
Truck center-of-gravity drop - Lowers the truck's primary center of gravity; higher drop = more stability.
Addon/trailer center-of-gravity drop - Lowers supported addon/trailer primary center of gravity. Not used for category targets because many trailers/addons are shared globally.

PRESETS
Vanilla / Reset - Returns editor fields to stock/default values.
Enhanced - Loads a moderate tuned preset.
Overpowered - Loads a much stronger preset.
Last applied values are saved automatically.

CATEGORY TARGETS
All Scouts / Highway / Heavy Duty / Off-Road / Heavy apply settings to every official truck in that class in one non-stacking batch. Shared resources are de-duplicated so multipliers are not repeatedly compounded.

NOTE
Not every SnowRunner truck/addon exposes every setting. WL modifies supported data it can safely identify and reports the changes in Preview/Apply results.

DIFFERENTIAL LOCK
-----------------
