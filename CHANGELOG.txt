v1.2.0 - Editable Third-Party Mod Trucks

New / Expanded

-   Turned Scan Mods from read-only discovery into protected editing of
    installed third-party mod trucks.
-   Added friendly Mod.io package names while retaining exact internal
    truck IDs for targeting.
-   Added feature-level compatibility: unsupported or inherited
    components can be skipped without rejecting the entire truck.
-   Added shared multi-truck PAK cumulative editing so edits to one
    truck do not overwrite earlier WL edits to sibling trucks in the
    same PAK.
-   Added protected external per-mod backup and Restore Original support
    with baseline verification.
-   Third-party mod backups are stored outside SnowRunner’s mod scan
    tree.
-   Added mod-local custom crane strength support when a safe compatible
    crane definition can be resolved.
-   Added service water capacity support alongside fuel, repair points,
    and spare wheels.
-   Added All Tires Ignore Ice using SnowRunner’s native
    IsIgnoreIce="true" property while preserving existing tire friction
    values.
-   Added heavy-recovery COG tuning improvements for supported official
    trucks.

Compatibility / Safety

-   Added compatibility handling for several malformed XML patterns
    tolerated by SnowRunner, including duplicate attributes, malformed
    comments, and bare ampersands.
-   Added keyed Gear structural merge support for the editor-generated
    forward gear.
-   Added shared-gearbox cumulative merge handling so legitimate prior
    WL edits can be preserved across trucks sharing a PAK/gearbox.
-   Unsafe or ambiguous feature targets fail closed at the narrowest
    safe scope.
-   Unsupported features are reported as skipped instead of forcing
    unsafe edits.
-   Custom mod crane speed intentionally remains stock where no
    known-safe universal free-movement control can be resolved.
-   Scan Mods no longer creates a Desktop discovery TXT file.
-   Improved UTF-8/BOM handling for Mod.io metadata and friendly names.
-   Existing protected backup, validation, Preview Changes, game-running
    lockout, and restore protections remain in place.

Validation

-   Preview compatibility torture test: 792 third-party truck
    definitions across 497 mod PAKs totaling 57.5 GB.
-   Result: 792/792 tested definitions safely handled in full or through
    feature-level compatibility.
-   Selected regression library: 39/39 real Apply tests succeeded.
-   In-game testing passed on the modified third-party fleet.
-   Individual Restore Original testing passed.
-   Shared multi-truck PAK Restore Original testing passed.
-   Final release build completed Apply / gameplay / Restore / gameplay
    smoke testing successfully.
-   These results describe the tested library and are not a claim of
    universal compatibility with every SnowRunner mod.

v1.2.0L PUBLIC UPDATE - AV CLEAN LAUNCHER / APPLY & PREVIEW FIXES
============================================================

Antivirus / Launcher

- Rebuilt the Windows launcher using a cleaner packaging architecture to reduce antivirus false positives.
- Removed the previous Base64-embedded PowerShell payload packaging method.
- Removed runtime extraction of the editor script to a temporary folder.
- Removed the previous powershell.exe child-process launch method.
- Removed use of -ExecutionPolicy Bypass.
- The launcher now hosts the Windows PowerShell automation engine in-process instead of launching an external PowerShell process.
- Added dynamic Windows PowerShell automation assembly discovery for broader Windows compatibility.
- Antivirus testing was completed on fresh builds without whitelisting before scan.
- No editor features were intentionally removed as part of the launcher change.

Cumulative Apply / Targeting Fixes

- Fixed a major cumulative-edit regression where applying changes to a single official truck after All Trucks or category edits could revert large portions of the existing modified PAK back toward stock.
- Single-truck Apply now uses the current live modified PAK as the output baseline while using the trusted original backup only as the calculation/reference baseline.
- Fixed multiplier stacking when applying a preset globally and then applying the same or overlapping values to a single truck.
- Fixed a PAK rebuild bug that could duplicate every archive entry during single-truck edits.
- Added surgical replacement of only the XML entries that actually changed during targeted official-truck edits.
- Verified cumulative editing across Restore Original -> All Trucks -> All Scouts -> single-truck workflows.
- Verified previous All Trucks and category edits remain intact after later single-truck Apply operations.
- Fixed duplicate truck entries appearing in the official Truck Target selector by de-duplicating discovered trucks by internal truck ID.

Shared Component Handling

- Added clearer Preview reporting for shared SnowRunner component families.
- Preview now warns when a selected truck uses shared engine, suspension, gearbox, wheel, or winch definitions that may also affect other base-game trucks.
- Single-truck mode continues to respect SnowRunner's native shared-component architecture rather than cloning or repointing shared component XMLs.
- Truck-specific values remain isolated where SnowRunner stores them directly in the selected truck's own XML.
- Confirmed in-game that shared engine-family edits can legitimately affect multiple trucks using the same engine family.

Preview / Interface

- Reworked Preview Changes into cleaner grouped sections such as Engine / Gearbox, Drivetrain, Steering / Suspension / Stability, Tires / Wheels, Recovery / Cranes, Service / Cargo, Durability, Access / Economy, and Other.
- Reduced the previous wall of raw rule/count output while preserving useful compatibility and shared-scope information.
- Fixed the Recovery & Cranes section label/layout so it is no longer partially hidden by the All Tires Ignore Ice control.
- Improved shared-component wording for single versus multiple affected base-game trucks.

Unlocks / Cranes / Regression Validation

- Preserved Unlock All Upgrades/Addons behavior across tested All Trucks, category, and single-truck Apply sequences.
- Verified official-truck crane strength and crane speed edits continue to apply correctly when the selected truck supports a compatible crane.
- Confirmed trucks without a compatible crane do not receive crane XML changes.
- Verified clean archive structure after Restore Original, All Trucks, category, and single-truck Apply operations.
- Verified no duplicate PAK entries were introduced during the tested workflows.
- Final regression testing passed in game for All Trucks, All Scouts/category overrides, single-truck overrides, shared-engine behavior, truck-local fuel changes, unlock preservation, and crane strength/speed changes.

Notes

- SnowRunner reuses many shared component families. A single-truck edit to a shared engine, suspension, gearbox, wheel, winch, or similar definition may also affect other trucks that reference the same component.
- The editor now reports this shared scope more clearly in Preview rather than attempting risky component cloning/repointing.
